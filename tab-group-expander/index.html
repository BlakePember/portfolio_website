TabGroup Expander.

A Manifest V3 Chrome extension that lets users expand and shrink Chrome tab groups via keyboard shortcuts or by dragging group borders in a real-time Side Panel.

KEY HIGHLIGHTS

How it works.

03 FEATURES
01

Keyboard-Driven Control

Global shortcuts (Alt+Shift+Left/Right/Down) to absorb adjacent tabs or shrink groups without touching the mouse, handling pinned tabs and neighboring group boundaries cleanly.

02

Interactive Drag Side Panel

Built a live-synced vertical tab strip using the chrome.sidePanel API and pointer-capture drag handles so users can drag group borders with their mouse to update Chrome's native tab bar in real time.

03

Privacy-First & Zero Dependencies

Runs 100% locally using minimal permissions (tabs, tabGroups, sidePanel) with no external libraries or data collection.
