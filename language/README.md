# Fala! — Learn Brazilian Portuguese

An interactive, 100% client-side Brazilian Portuguese (*Português Brasileiro*) learning app built with React, TypeScript, and Vite.

## Features
- **8 Progressive Guided Units (A0 → A2):** Greetings, Introductions & *Ser/Estar*, Food & Café, City & Directions, Daily Routine & Time, Family & Feelings (*Saudade*), Verbs in Action, and Real Brazilian Slang.
- **Mixed Active-Recall Lessons:** Brazilian `pt-BR` audio comprehension, translation, fill-in-the-blank, sentence word-bank builder, and accent-assisted typing (`á â ã à ç é ê í ó ô õ ú`) with accent-aware grading.
- **SM-2 Spaced Repetition Flashcards:** Full deck + starred bookmarks + searchable glossary + ability to add custom personal phrases.
- **Brazilian Verb Trainer:** 20 essential verbs across Present, Simple Past, Imperfect, and Spoken Future (`ir + infinitive`) focused on real Brazilian pronouns (`eu, você / a gente, nós, vocês`).
- **6 Real-Life Brazilian Dialogues:** Listen & Read Along or practice responding in interactive Roleplay mode (São Paulo padaria, Rio beach friend, Belo Horizonte lunch, Salvador directions, Florianópolis market, Curitiba WhatsApp).
- **Pronunciation & Survival Guide:** Interactive `pt-BR` soundboard (R→H, DI→J, TI→CH, final L→W, nasal `ão`), grammar & spoken contractions (`no/na`, `tô/tá`, `pra`, `né?`), *Ser vs. Estar*, and false friends.

## Local Development

```bash
cd language
npm install
npm run dev      # http://localhost:5175
npm test         # Vitest unit tests
npm run build    # Typecheck + production build to dist/
```
